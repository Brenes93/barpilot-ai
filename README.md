# BarPilot AI

BarPilot AI is a Full Stack project created to learn modern web development using React, TypeScript, and professional development tools.

The project is currently under development and serves as a hands-on learning environment to gain practical experience in:

* React
* TypeScript
* Git and GitHub
* Frontend Development
* Backend Development (coming soon)
* Full Stack Application Architecture

---

## Project Goals

The main goal of this project is to build a management application for the hospitality industry while learning programming fundamentals, software architecture, and professional development workflows.

Planned features include:

* Employee management
* Schedule management
* Inventory management
* Administration dashboard
* Authentication system
* AI-powered features

## Installation

Clone the repository:

```bash
git clone https://github.com/Brenes93/barpilot-ai.git
```

Navigate to the frontend folder:

```bash
cd barpilot-ai/frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
